# Shiraali Search — کدهای بازیابی‌شده و ماژول‌های مستقل (نسخهٔ آزمایشی)

## فایل‌ها
- `index-recovered.html`: نسخهٔ بازیابی‌شده از فایل گفت‌وگو در ۱۴ اکتبر ۲۰۲۶. این فایل برای حفظ نسخهٔ فعلی است؛ تضمین نمی‌شود عین نسخهٔ زندهٔ GitHub باشد.
- `modules/general.js`: جست‌وجوی عمومی؛ حداکثر ۱۱ نتیجه.
- `modules/special.js`: جست‌وجوی سایت‌های ویژه؛ حداکثر ۱۱ نتیجه.
- `modules/social.js`: جست‌وجوی شبکه‌های اجتماعی؛ حداکثر ۱۱ نتیجه.
- `modules/images.js`: گالری تصویر مستقل با حداکثر ۱۱ تصویر.
- `modules/graphical.js`: توابع مستقل ساعت و آب‌وهوا؛ ساعت محلی و دادهٔ آب‌وهوا از Open-Meteo.
- `modules/shared-general.js`, `shared-special.js`, `shared-social.js`: نسخه‌های جداگانهٔ کمکیِ هر بخش؛ عمداً فایل کمکی مشترک ندارند.
- `module-demo.html`: پیش‌نمایش ساده برای آزمودن ماژول‌ها؛ جایگزین index فعلی نیست.

## نکتهٔ مهم پیش از انتشار
این بسته یک پیش‌نویس ماژولار برای بازبینی و آزمایش است، نه انتشار انجام‌شده. ماژول‌های جست‌وجو از API فعلی `https://shiraali-search.onrender.com/search` استفاده می‌کنند؛ بنابراین جداسازی کدهای مرورگر به‌تنهایی به معنی جداسازی واقعی سرویس‌های Render نیست. برای استقلال کامل سرویس‌ها باید برای هر سرویس، بک‌اند جداگانه ساخته و در Render مستقر شود و سپس نشانی API هر بخش تنظیم شود.

برای آزمودن `module-demo.html` بهتر است آن را با یک وب‌سرور محلی یا GitHub Pages باز کنید؛ بعضی مرورگرها import ماژول‌های جاوااسکریپت از `file://` را مسدود می‌کنند.

هیچ فایل زنده‌ای در GitHub یا Render با این بسته تغییر نکرده است.


## بک‌اندهای پنج بخش (پیش‌نویس)
پوشهٔ `backends/` شامل پنج سرویس مستقل پیشنهادی است. این‌ها هنوز deploy نشده‌اند و تنظیمات SearXNG باید قبل از انتشار آزمایش شوند. راهنما در `BACKEND-SETUP.md` است. نسخهٔ `index-recovered.html` صرفاً پشتیبان بازیابی‌شده است؛ آن را روی نسخهٔ زنده جایگزین نکن.
